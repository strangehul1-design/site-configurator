# Конфигуратор сайта — «Digital для бизнеса»

Страница, на которой человек сам собирает сайт: выбирает нишу, оформление и блоки,
а рядом в рамке страница собирается прямо на глазах. В конце — ТЗ, ссылка на
собранный вариант и кнопки, чтобы прислать сборку мне.

Сайт: <https://strangehul1-design.github.io/site-configurator/> (английский),
русская версия — `/ru/`. Портфолио: <https://strangehul1-design.github.io/web-chef-portfolio/>.

Всё работает в браузере: ни одна заявка никуда не уходит, сборка хранится в адресе
страницы (`#n=…&t=…&b=…`), поэтому ссылку можно отправить клиенту — откроется ровно
его вариант.

## Как устроено

| Файл | Что внутри |
| --- | --- |
| `index.html`, `ru/index.html` | оболочка: шапка, вступление, пустые контейнеры для шагов и рамки |
| `assets/css/app.css` | стили конфигуратора (палитра и шрифты портфолио) |
| `assets/js/data.js` | всё содержимое: нишы, оформления, блоки, подписи — в двух языках |
| `assets/js/preview.js` | сборка страницы в рамке: свои стили, разметка блоков, «открыть целиком» |
| `assets/js/app.js` | состояние, адрес-ссылка, масштаб рамки, ТЗ и отправка |
| `tools/serve.mjs` | локальный просмотр, повторяет адрес GitHub Pages |

Рамка предпросмотра — `<iframe srcdoc>`, то есть того же происхождения. Поэтому при
щелчке страница не перезагружается: меняются переменные темы и добавляется или
убирается один блок. Из-за этого и видно, как сайт собирается.

## Содержимое предпросмотра

Внутри демо-страницы — заполнители, а не выдуманные факты: название вымышленное и
подписано как демо, цены показаны как «от 0 000 ₽», отзывы — «здесь будет отзыв
клиента», адрес — «адрес подставим ваш». Так и должно оставаться: придуманные
цены, отзывы и цифры результата в конфигуратор не добавляем.

## Что можно поменять

**Новая ниша.** Добавить объект в `niches` (`assets/js/data.js`): нужны `label`,
`hint`, `brand`, `mark`, `nav`, `h1`, `lead`, `cta`, `cta2`, `stats` (3 пары),
`services` (3 пары), `gallery` (4 подписи), `price` (3 пары), `faq` (3 пары),
`place` (3 строки) — и всё это в `ru` и `en`. Значок — ключ из `icons` в `app.js`.

**Новое оформление.** Объект в `themes`: `swatch` (три цвета для кружков), `font`
(часть адреса Google Fonts) и `tokens`. Токен `accent` — заливка кнопок, `accent-2` —
акцентный текст: на тёмном фоне это разные цвета. Проверьте контраст: текст к фону
не ниже 4,5:1.

**Новый блок.** Объект в `blocks` (порядок массива = порядок на странице) и функция
с тем же `id` в `sections` (`preview.js`). Блок `messengers` особенный: он не секция,
а кружки в углу экрана.

**Цены.** Строки `priceMain`, `priceMainNote`, `priceRows`, `priceNote` в `ui`
(`data.js`). Сейчас там «от 26 000 ₽», хостинг 5 038 ₽/год и домен 169 ₽/год —
то же, что в смете. Отдельной цены за каждый блок намеренно нет.

## Локальный просмотр

```
node tools/serve.mjs
```

Откроется по адресу <http://localhost:4700/site-configurator/> — путь такой же, как
на GitHub Pages, поэтому относительные ссылки ведут себя одинаково.

## Правки

Правим в отдельной ветке и через PR: пуш в `main` сразу публикует сайт. Тексты
меняем сразу в обоих языках — ключи в `ru` и `en` должны совпадать.
